# 妙妙工作台 · 个人医美工作台

一个专为医美顾问设计的移动端工作台应用。

## 功能模块

1. **每日工作** - 10项每日任务跟踪，可打勾完成，12:00和16:00自动提醒
2. **皮肤专业** - 皮肤分层解剖学+问题肌肤病理知识，每日10条
3. **光电专业** - 光电仪器功效、品牌、新品动态，每日10条
4. **水光产品** - 水光产品功效、品牌、价格资讯，每日10条
5. **注射微整** - 注射类产品功效、品牌、价格动态，每日10条
6. **护肤成分** - 主流护肤成分功效解说，每日10条
7. **美学设计** - 美学设计理念与变美方案，每日10条
8. **朋友圈文案** - 13种分类文案+图片，每日10条，支持手动刷新
9. **运动拉伸** - 按身体部位分类的运动拉伸视频
10. **英语学习** - 零基础分阶段学习规划，美式标准发音
11. **财经资讯** - 每日世界大事与国内财经资讯
12. **心理学知识** - 心理学知识推荐
13. **任务日历** - 日历打卡，4色标记（粉/黄/红/灰），支持请假
14. **记账功能** - 每日记花销，月度汇总，分类统计，支持删除
15. **内容创作** - 医美爆款热点视频推荐+二创建议
16. **设置** - 任务增删改查，语音开关，数据导出

## 特色功能

- 🎵 柔和女声语音播报（舒缓语速）
- ⏱ 任务计时器
- 📅 日历打卡（4色标记）
- 💾 本地数据持久化（localStorage）
- 📱 移动端优先设计，女性化愉悦风格

## 技术栈

- 纯 HTML/CSS/JavaScript（无框架依赖）
- SVG 占位图生成
- Web Speech API 语音合成
- Web Speech API 语音识别（录音纠音）
- localStorage 数据存储

## GitHub Pages 部署

2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支
4. 保存后等待部署完成
5. 访问 `https://你的用户名.github.io/仓库名/`
